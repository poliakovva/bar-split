# bar-split

https://poliakovva.github.io/bar-split/

кто за что скинул по чеку из бара: 40 084 ₽, 29 строк чека, 50 позиций.

- **друзья**: пишут имя, тапают свои коктейли и еду (повторный тап — доля ½ / ⅓ / ¼), переводят и жмут «я перевёл». владу уходит сообщение со ссылкой.
- **влад**: открывает ссылку, сверяется с банком, жмёт «деньги пришли ✓». отметка пишется в `state.json` и видна всем.

вход для влада: `…/#admin` + fine-grained токен github только на этот репо с правом **contents: read and write**. токен хранится только в localStorage браузера.
